# Contexa 商店截图脚本 / Store Screenshots Script

> 5 张截图，1280×800，PNG。每张配标题文案。
> 拍摄建议：用真实的高保真原型页面（如 Figma 导出的 HTML 或公开 demo 站），开启对应主题，截图时确保侧边栏可见。
> 文字叠加层建议用 Figma / Sketch 制作，字体用 SF Pro 或 PingFang SC。

---

## 总体设计规范

- **尺寸**：1280×800 px
- **背景**：浅色（与 Minimal 主题一致的 `#fafafa`）或对应主题色
- **文字叠加**：顶部或左上角放标题，字号 32-40px，粗体；副标题 18-22px，常规
- **侧边栏**：建议展开，展示 Contexa 真实 UI
- **配色**：遵循 Contexa 的低饱和度风格，不要用高饱和红绿

## 制作流程建议

1. 先准备一个干净的 demo 页面（建议用你自己的高保真原型，或公开的 UI kit demo）
2. 在该页面授权 Contexa，分别切到标注/云端模式操作一遍，录屏备用
3. 逐张截图，确保 pin 位置、弹窗内容、侧边栏状态都符合脚本
4. 用 Figma 叠加标题文字层
5. 导出 PNG，命名 `screenshot-1.png` ~ `screenshot-5.png`，放 `store/assets/`

## 短视频脚本（可选，30 秒内）

| 时间 | 画面 | 旁白/字幕 |
| --- | --- | --- |
| 0-5s | 打开网页，点击 Contexa 图标 | 「指出你要说明的页面元素」 |
| 5-12s | 标注模式，点击按钮，弹出编辑框输入备注 | 「补充需求、反馈或验收意见」 |
| 12-18s | 导出 JSON，上传（模拟），侧边栏配置云端 URL | 「一键导出，云端共享」 |
| 18-25s | 接收者打开同页面，云端模式自动加载备注 | 「团队打开即见，AI 读取即懂」 |
| 25-30s | 主题切换快剪 + 域名管理 + logo | 「Contexa — Point → Explain → Hand off」 |
