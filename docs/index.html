⚙️ 如何工作⚙️ How It Works

四步把网页上下文交付给团队或 AIFour steps to hand off web context to teams or AI

1

指出页面元素Point

在网页或 HTML 原型上点击元素，精准确定说明对应的位置。Click an element on a web page or HTML prototype to pinpoint the relevant location.

2

补充上下文Explain

用标题和详细描述记录需求、反馈、缺陷或验收意见。Add a title and details for requirements, feedback, defects, or acceptance notes.

3

导出结构化数据Export

一键导出包含元素定位和说明内容的 JSON，可共享、可版本管理。Export JSON containing element locations and notes, ready to share or version.

4

交付团队或 AIHand off

上传 JSON 后，团队通过 URL 在原页面查看，或由 AI 直接读取结构化数据。Host the JSON for teams to review on the original page, or hand it directly to AI.

🔒 隐私优先🔒 Privacy-First

按需授权，数据自主On-demand permission, you own your data

Contexa 安装时不索取任何网站权限。仅当你在某个网站首次标注时，Chrome 才弹出授权提示并明确显示具体子域名，由你主动决定。所有标注数据仅存本地浏览器，不上传任何服务器。可在「域名管理」随时撤销授权。 Contexa requests no website permissions at install. Only when you first annotate a site does Chrome prompt — clearly showing the exact subdomain — and you decide. All annotation data stays in your local browser, never uploaded to any server. Revoke access anytime in "Domain Management".
